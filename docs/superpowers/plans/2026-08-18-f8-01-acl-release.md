# F8-01 ACL Command Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow the release capability to invoke the four existing GUI/runtime commands required by WUT-36 and produce a verified Windows release binary.

**Architecture:** Keep the existing Tauri command handlers and `default` capability unchanged. Extend only the application-owned `app-commands` permission set, regenerate the checked-in ACL manifest during the Tauri build, and protect the allowlist with a small PowerShell contract test.

**Tech Stack:** Tauri CLI 2.11.4, Rust/Cargo, Svelte/Vite, PowerShell 7.

---

### Task 1: Add the failing ACL contract test

**Files:**
- Create: `scripts/acceptance/wut-36-acl.tests.ps1`

- [ ] **Step 1: Write the failing test**

Create this self-contained PowerShell test:

```powershell
$ErrorActionPreference = "Stop"

$permissionPath = Join-Path $PSScriptRoot "..\..\src-tauri\permissions\app-commands.toml"
$manifestPath = Join-Path $PSScriptRoot "..\..\src-tauri\gen\schemas\acl-manifests.json"
$requiredCommands = @(
    "is_game_running",
    "browse_game_folder",
    "save_settings",
    "load_settings"
)

if (-not (Test-Path -LiteralPath $permissionPath -PathType Leaf)) {
    throw "Permission source not found: $permissionPath"
}
if (-not (Test-Path -LiteralPath $manifestPath -PathType Leaf)) {
    throw "Generated ACL manifest not found: $manifestPath"
}

$permissionText = Get-Content -Raw -LiteralPath $permissionPath
$manifest = Get-Content -Raw -LiteralPath $manifestPath | ConvertFrom-Json
$allowedCommands = @($manifest.'__app-acl__'.permissions.'app-commands'.commands.allow)

foreach ($command in $requiredCommands) {
    if ($permissionText -notmatch ('(?m)^\s*"' + [regex]::Escape($command) + '",?\s*$')) {
        throw "ACL source is missing required command: $command"
    }
    if ($allowedCommands -notcontains $command) {
        throw "Generated ACL manifest is missing required command: $command"
    }
}

Write-Output "PASS: WUT-36 ACL command contract"
```

- [ ] **Step 2: Run the test to verify it fails for the known defect**

Run:

```powershell
pwsh -NoProfile -File scripts/acceptance/wut-36-acl.tests.ps1
```

Expected: non-zero exit with `ACL source is missing required command: is_game_running`.
